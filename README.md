# 🧑‍💻 Git & GitHub Assignment

This repository was created as part of **Assignment 1: Git & GitHub**.  
It demonstrates how to create, manage, and synchronize local and remote Git repositories.  
All major Git operations such as initialization, staging, committing, pushing, and creating a professional README file have been performed in this project.

---

## 🎯 Objectives

The main objectives of this assignment are:

- ✅ Create a **local Git repository** and make multiple commits.  
- ✅ Create a **remote repository** on **GitHub**.  
- ✅ Synchronize the **local repository** with the **remote repository** (push/pull).  
- ✅ Understand and apply the **basic Git workflow:**  
  `git add → git commit → git push`
- ✅ Create a **well-structured README.md** file using Markdown.  
- ✅ Share the work **publicly on GitHub**.
